# Самостоятельная работа с преподавателем — Тема 2 (`t02/srsp/`)

> **Пояснение к вопросу из задания:**
> Число $0$ состоит из **одной** цифры ($1$), а сумма его цифр равна $0$. Чтобы обработать ввод $n = 0$ единым алгоритмом без добавления лишних условий `if (n == 0)`, необходимо применять **цикл с постусловием** (`do ... while`). Такой цикл выполняет тело минимум один раз до проверки условия продолжения $n > 0$.

---

## 1. Описание алгоритма на псевдокоде

```text
начало_алгоритма РазборЧисла
    ввод n
    если (n не целое) ИЛИ (n < 0) то
        вывод "Некорректные данные: требуется целое число >= 0"
    иначе
        сумма := 0
        количество := 0
        повторять
            остаток := n mod 10
            сумма := сумма + остаток
            количество := количество + 1
            n := n div 10
        пока n > 0
        вывод количество, сумма
    конец_если
конец_алгоритма
```

## 2. Построение блок-схемы по ГОСТ 19.701-90 (инструкция для draw.io)

Разместите элементы вертикально сверху вниз и соедините направленными линиями:

1. **Блок «Терминатор» (скругленный прямоугольник):** текст `Начало`.
2. **Блок «Данные» (параллелограмм):** текст `Ввод n`.
3. **Блок «Решение» (ромб):** условие `n — целое И n >= 0`.
   * **Выход «Нет» (вправо):** ведет к блоку **«Данные»** с текстом `Вывод сообщения об ошибке`, откуда линия идет сразу к финальному терминатору `Конец`.
   * **Выход «Да» (вниз):** переход к инициализации переменных.
4. **Блок «Процесс» (прямоугольник):**
   `сумма := 0`
   `количество := 0`
5. **Блок «Процесс» (прямоугольник — шаги цикла):**
   `сумма := сумма + (n mod 10)`
   `количество := количество + 1`
   `n := n div 10`
6. **Блок «Решение» (ромб — постусловие):** условие `n > 0`.
   * **Выход «Да» (влево и наверх):** линия возвращается в точку перед блоком №5.
   * **Выход «Нет» (вниз):** выход из цикла.
7. **Блок «Данные» (параллелограмм):** текст `Вывод количество, сумма`.
8. **Блок «Терминатор» (скругленный прямоугольник):** текст `Конец`.

## 5. Результаты контрольных проверок

* **Вход `472`** $\rightarrow$ Цифр в числе: `3`, Сумма цифр: `13`
* **Вход `0`** $\rightarrow$ Цифр в числе: `1`, Сумма цифр: `0`
* **Вход `7`** $\rightarrow$ Цифр в числе: `1`, Сумма цифр: `7`
* **Вход `1000`** $\rightarrow$ Цифр в числе: `4`, Сумма цифр: `1`
* **Вход `-5` или `текст`** $\rightarrow$ Вывод сообщения об ошибке ввода.
