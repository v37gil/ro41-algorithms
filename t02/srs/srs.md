## Задание А. Трассировка цикла с параметром (при $n = 5$)

**Исходный алгоритм:**
* Входное значение: $n = 5$
* Начальная установка: $f := 1$
* Цикл: для каждого $i$ от $1$ до $n$ выполнять $f := f \cdot i$

| Шаг (итерация) | Значение $n$ | Счётчик $i$ | Накопитель $f$ ($f \cdot i$) |
| :---: | :---: | :---: | :---: |
| До входа в цикл | $5$ | не определено | $1$ |
| Итерация $1$ | $5$ | $1$ | $1 \cdot 1 = 1$ |
| Итерация $2$ | $5$ | $2$ | $1 \cdot 2 = 2$ |
| Итерация $3$ | $5$ | $3$ | $2 \cdot 3 = 6$ |
| Итерация $4$ | $5$ | $4$ | $6 \cdot 4 = 24$ |
| Итерация $5$ | $5$ | $5$ | $24 \cdot 5 = 120$ |

**Итоговый вывод алгоритма (`f`):** `120`

## Задание Б. Трассировка цикла с предусловием (`пока x < 100`)

**Исходный алгоритм:**
* Начальные значения: $x := 3$, $k := 0$
* Цикл: пока выполняется $x < 100$, удваивать $x$ ($x := x \cdot 2$) и увеличивать счётчик $k$ ($k := k + 1$)

| Шаг (итерация) | Проверка условия ($x < 100$) | Переменная $x$ | Счётчик $k$ |
| :---: | :---: | :---: | :---: |
| До входа в цикл | — | $3$ | $0$ |
| Итерация $1$ | $3 < 100$ (`Да`) | $6$ | $1$ |
| Итерация $2$ | $6 < 100$ (`Да`) | $12$ | $2$ |
| Итерация $3$ | $12 < 100$ (`Да`) | $24$ | $3$ |
| Итерация $4$ | $24 < 100$ (`Да`) | $48$ | $4$ |
| Итерация $5$ | $48 < 100$ (`Да`) | $96$ | $5$ |
| Итерация $6$ | $96 < 100$ (`Да`) | $192$ | $6$ |
| Выход из цикла | $192 < 100$ (`Нет`) | $192$ | $6$ |

**Итоговый вывод алгоритма (`x, k`):** `192, 6`
