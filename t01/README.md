# СРСП 1. Перевод секунд в часы, минуты и секунды

## 1. Словесная запись алгоритма
1. Запросить у пользователя ввод целого неотрицательного числа секунд.
2. Проверить ввод: если строка не число или число меньше 0, вывести сообщение об ошибке и завершить программу.
3. Вычислить часы: H = S / 3600 (целочисленное деление).
4. Вычислить остаток секунд: S_ost = S % 3600.
5. Вычислить минуты: M = S_ost / 60.
6. Вычислить секунды: Sec = S_ost % 60.
7. Вывести результат в виде: H ч. M мин. Sec сек.
