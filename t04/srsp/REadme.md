## 1. Описание схемы верхнего уровня по ГОСТ 19.701-90 (для draw.io)

В схеме верхнего уровня обращения к методам класса `Grades` (`Read`, `IsValid`, `PrintStats`) изображаются фигурой **«Предопределённый процесс»** (прямоугольник с дополнительными вертикальными линиями слева и справа).

Схема строится следующим образом:

1. **Терминатор:** `Начало`.
2. **Процесс (прямоугольник):**
   `count := 0`
   `sum := 0`
   `fives := 0`
3. **Предопределённый процесс (двойные боковые линии):**
   `g := Grades.Read()`
4. **Решение (ромб — условие цикла):** `g != Grades.Stop`
   * **Выход «Да» (вниз — тело цикла):**
     * **Предопределённый процесс / Решение:** проверка `Grades.IsValid(g)`
       * **Выход «Да» (оценка корректна):**
         * **Процесс:**
           `count := count + 1`
           `sum := sum + g`
         * **Решение:** `g = Grades.Max`
           * **«Да»:** **Процесс** `fives := fives + 1`
           * **«Нет»:** пропуск увеличения `fives`.
       * **Выход «Нет» (оценка некорректна):**
         * **Данные (параллелограмм):** `Вывод сообщения о неверной оценке`.
     * **Предопределённый процесс (в конце тела цикла):**
       `g := Grades.Read()`
     * Возврат линии потока на вход ромба №4 (`g != Grades.Stop`).
   * **Выход «Нет» (вправо — завершение цикла):**
5. **Предопределённый процесс (двойные боковые линии):**
   `Grades.PrintStats(count, sum, fives)`
6. **Терминатор:** `Конец`.
